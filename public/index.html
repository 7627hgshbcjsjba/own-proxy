own-proxy

Your own proxy URL server — browse any site through yourhost/p/<host>/…

Tip: typing a domain goes straight to the proxied page. Everything you click stays inside the proxy.

How it works

Every target site keeps its real path, but the address becomes yours: http://your-server:8080/p/<host>/<path>. The server downloads the page, rewrites every link, image, stylesheet and script to point back at itself, and streams it to your browser. Forms, cookies and XHR requests are forwarded to the real site.

API

GET /api/proxy-url?url=https://example.com → returns the proxy URL for any address.

GET /health → server status.

Notes

Login-protected sites and heavy JS SPAs can behave oddly because the site still sees requests coming from your server. Private/internal addresses are blocked by default to stop the proxy being abused. Set ALLOW_PRIVATE_NETWORKS=1 if you need to reach hosts on your LAN.
